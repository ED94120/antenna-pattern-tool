# ============================================================
# Fichier : antenna-specs.txt
# Objet   : informations descriptives et caractéristiques
#           synthétiques des antennes.
#
# RÈGLES DE STRUCTURE POUR LE PARSEUR
# ============================================================
#
# 1. Chaque fiche antenne commence obligatoirement par :
#
#    [ANTENNA] Nom_Antenne
#
#    Le nom doit être unique.
#    Si un fichier d'atténuation existe pour cette antenne, ce nom doit être
#    strictement identique à la première ligne du fichier d'atténuation.
#
# 2. Les lignes commençant par # sont des commentaires.
#    Elles doivent être ignorées par le parseur.
#
# 3. Les lignes descriptives libres sont autorisées.
#    Elles peuvent être affichées telles quelles à l'utilisateur.
#
# 4. Les angles d'ouverture doivent être écrits avec les clés suivantes :
#
#    Angle 3dB azimut :
#    Angle 3dB elevation :
#
#    La forme recommandée est :
#
#    Angle 3dB azimut : Bande BF 72°, Bande MF_HF 66°.
#    Angle 3dB elevation : Bande BF 7.6°, Bande MF_HF 7.7°.
#
# 5. Le mot "Bande" doit précéder le nom de bande.
#    Le nom de bande ne doit pas contenir d'espace.
#
#    Exemples valides :
#    Bande BF 72°
#    Bande MF 69.4°
#    Bande HF 59°
#    Bande MF_HF 67.8°
#    Bande 3500MHz 100°
#    Bande General 100°
#
# 6. Pour une antenne sans découpage par bandes, utiliser :
#
#    Bande General
#
#    Exemple :
#    Angle 3dB azimut : Bande General 100°.
#    Angle 3dB elevation : Bande General 23°.
#
# 7. Les valeurs numériques peuvent utiliser le point décimal.
#    Exemple : 68.7°
#
#    L'utilisation de la virgule décimale est tolérée si le parseur la convertit.
#    Exemple : 68,7°
#
# 8. La longueur du radôme doit être écrite avec la clé suivante :
#
#    Longueur radome :
#
#    Exemple :
#    Longueur radome : 2.695 m
#
#    Si elle n'est pas connue :
#    Longueur radome : non renseignee
#
# 9. Pour faciliter le parsing, éviter les accents dans les clés structurées.
#    Les accents restent autorisés dans les textes descriptifs libres.
#
# 10. Les unités recommandées sont :
#
#    angles : degrés, symbole °
#    longueur : m
#
# ============================================================
